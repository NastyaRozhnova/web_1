# Nautilus — Vinyl & CD Store

Проект интернет-магазина виниловых пластинок и CD

Сайт разработан на чистых HTML, CSS и JavaScript без использования фреймворков

## Функциональность

- каталог виниловых пластинок и CD;
- добавление товаров в корзину;
- изменение количества товаров;
- удаление товаров из корзины;
- автоматический подсчёт общей стоимости;
- сохранение корзины в `localStorage`;
- восстановление корзины после обновления страницы;
- форма оформления заказа;
- уведомления о состоянии заказа;
- адаптивная верстка для компьютеров, планшетов и смартфонов.

## Технологии

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
- Media Queries
- LocalStorage
